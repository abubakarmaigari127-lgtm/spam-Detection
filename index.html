📧 Spam Detection System

Complete Setup & Installation Guide

1 Install Python

Python is the programming language used for this application. If you don't have it installed, follow these instructions:

📥 Download Python

Visit the official Python website: https://www.python.org/downloads/

Download the latest version for your operating system (Windows, macOS, or Linux). Look for the "Download Python X.Y.Z" button.

🔧 Run the Installer

  • Windows: Double-click the downloaded .exe file.
  • macOS: Double-click the downloaded .pkg file and follow the prompts.
  • Linux: Python is often pre-installed. Open a terminal and type python3 --version to check.
⚠️ Important for Windows Users: During installation, make sure to check the box that says "Add Python to PATH". This is crucial for the next steps!

✅ Verify Installation

Open your computer's Command Prompt (Windows) or Terminal (macOS/Linux) and type:

python --version

or

python3 --version

You should see the Python version printed (e.g., Python 3.11.0).

✓ Success: If you see a version number, Python is installed correctly!

2 Extract Project Files

Now we'll extract the spam detection system files to your computer.

📂 Locate the Zip File

You should have a file named spam_detection_system.zip in your Downloads folder or wherever you saved it.

📦 Extract the Contents

  • Windows: Right-click on spam_detection_system.zip and select "Extract All".
  • macOS: Double-click the zip file to automatically extract it.
  • Linux: Right-click and select "Extract Here" or use the terminal command: unzip spam_detection_system.zip

This will create a new folder named spam_detection_system.

📍 Remember the Folder Location

Note where this folder is located. For example:

  • Windows: C:\Users\YourName\Downloads\spam_detection_system
  • macOS: /Users/YourName/Downloads/spam_detection_system
  • Linux: /home/YourName/Downloads/spam_detection_system
✓ Ready: You now have all the project files extracted and ready to use!

3 Open Command Prompt & Navigate to Folder

We need to open a command prompt (or terminal) and navigate to the project folder.

🖥️ Open Command Prompt/Terminal

  • Windows: Search for "cmd" or "Command Prompt" in the Start menu and click it.
  • macOS: Search for "Terminal" in Spotlight (Cmd + Space) and open it.
  • Linux: Right-click on your desktop and select "Open Terminal Here" or search for "Terminal" in your applications.

📍 Navigate to the Project Folder

In the Command Prompt/Terminal, type the following command (replace the path with your actual folder location):

cd path/to/your/spam_detection_system

For example, if it's in your Downloads folder on Windows:

cd C:\Users\YourName\Downloads\spam_detection_system

On macOS:

cd /Users/YourName/Downloads/spam_detection_system

Press Enter after typing the command.

💡 Tip: You can also drag and drop the folder into the terminal window, and it will automatically type the path for you!
✓ Ready: You should now see the folder path in your command prompt!

4 Install Required Libraries

Now we'll install all the necessary libraries that the application needs to run.

📦 Install Dependencies

In the Command Prompt/Terminal (where you are in the spam_detection_system folder), type:

pip install -r requirements.txt

If that doesn't work, try:

pip3 install -r requirements.txt

Press Enter and wait. This process might take a few minutes.

⏳ Be Patient: You will see messages indicating that packages are being downloaded and installed. This is normal. Do not close the terminal window!

✅ Verify Installation

When the installation is complete, you should see a message indicating success. The command prompt should be ready for the next command.

✓ Complete: All required libraries are now installed!

5 Run the Application

Now it's time to start the Spam Detection System application!

🚀 Start the Application

In the same Command Prompt/Terminal window, type:

streamlit run app.py

Press Enter.

🌐 Open in Browser

The application will start, and a new tab in your web browser should automatically open. If it doesn't, look for a message in the terminal that says:

Local URL: http://localhost:8501

Copy this URL and paste it into your web browser's address bar.

✓ Success: The Spam Detection System is now running in your browser!
💡 Note: Keep the Command Prompt/Terminal window open while using the application. To stop the application, press Ctrl + C in the terminal.

6 Use the Application

Great! The application is now running. Here's how to use it:

📝 Single Message Analysis

  • In the "Message Analysis" section, click the text area.
  • Type or paste any message you want to check.
  • Click the "🔍 Predict" button.
  • The application will display whether the message is "Spam" or "Not Spam (Ham)" along with a confidence score.

📊 Prediction History

Every time you make a prediction, it will be added to the "Prediction History" table below. You can:

  • View all your predictions from the current session.
  • See the message, prediction result, and confidence score.
  • Click "Clear History" to remove all predictions.

📁 Batch Prediction (Advanced)

In the "Batch Prediction" section on the right, you can:

  • Upload a CSV file containing a column named message.
  • The application will predict all messages in the file.
  • Download the results as a CSV file.

📈 View Model Performance

Click on "📊 View Model Performance Metrics" to see:

  • The confusion matrix (showing how accurate the model is).
  • Model accuracy and other performance metrics.
✓ Ready to Use: You can now start classifying messages as spam or not spam!

? Troubleshooting

If you encounter any issues, here are some common problems and solutions:

❌ Error: "'python' is not recognized" or "'pip' is not recognized"

This means Python was not added to your system's PATH during installation. Solution: Re-run the Python installer and ensure the "Add Python to PATH" option is checked during setup.

❌ Error: "No module named 'streamlit'"

This means the libraries were not installed correctly. Solution: Make sure you are in the spam_detection_system directory in your terminal and try running pip install -r requirements.txt again.

❌ Error: "No module named 'sklearn'" or other missing modules

Some libraries may not have installed properly. Solution: Try running pip install --upgrade pip first, then run pip install -r requirements.txt again.

❌ Browser doesn't open automatically

Solution: Look for a message in the terminal that says "Local URL: http://localhost:8501". Copy this URL and paste it into your web browser's address bar manually.

❌ Port 8501 is already in use

Solution: Another application is using this port. Try running: streamlit run app.py --server.port 8502 to use a different port.

❌ Application runs but shows errors

Solution: Check the terminal window for error messages. Take a screenshot of the error and share it for assistance.

Still having issues? If you encounter any persistent problems not listed above, please describe the exact error message you see, and we will do our best to assist you further.
